# Yhwach — The Almighty

This folder now contains source assets for the Yhwach animation/cutscene project. The Roblox Studio runtime implementation has been removed from the current branch.

## Remaining files

- `YhwachCutscenes.lua` — client-side cinematic UI/effects source; not a standalone loader.
- `Assets/Animations/` — original `.anim` source files.
- `Assets/Audio/`, `Assets/Effects/`, and `Assets/Accessories/` — asset placeholders and notes.

## Runtime status

No Delta/executor loader is included in this repository at present. Roblox Studio scripts and executor-only APIs are different environments; do not expect this asset folder alone to run as a complete system. The removed files remain available in Git history if you need to restore the Studio implementation later.

# NAM — by mamalalanam

NAM is a personal anime-animation hub. New anime animations will be added by the owner as they are supplied.

## Current direction
- Project branding: **NAM — by mamalalanam**
- Keep: **Hakari's Dance** and **Patchma Hub**
- Planned: owner-provided anime animations and a car animation entry
- Remove: unrelated TikTok/trend dances and unused animation packs
- Target: a clean, organized animation library with consistent naming and updated references

## Animation asset format
Place owner-provided animation files in `content/` using the existing `.anim` format, and provide the display name plus any required supporting assets (such as audio). Do not add placeholders that point to nonexistent files.

## Important
The upstream Uhhhhhh project is an executor-dependent reanimation program. Removing its reanimation engine without replacing its loader and rig/animation runtime would leave the program nonfunctional. This repository is being reorganized for NAM; the engine has not yet been removed, so this README does not claim that reanimation removal is complete.

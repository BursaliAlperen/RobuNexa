# RobuNexa AI Roblox Studio Plugin

Native Studio dock panel using Noxery's OpenAI-compatible API.

Features:
- Generate Luau from prompts
- Use selected Script / LocalScript / ModuleScript as context
- Fix selected script
- Insert generated Script into ServerScriptService
- Replace selected script
- API key stored locally with Plugin Settings
- No loadstring/runtime exploit loader

Install:
1. Roblox Studio > Plugins > Plugin Management > Load Local Plugin.
2. Select RobuNexaChatGPT.plugin.lua.
3. Open RobuNexa AI.
4. Create a Noxery API key and paste the nox- key.
5. Prompt and Generate.

API: https://api.noxery.net/v1/chat/completions
Default model: gpt-6-astra

Review generated code before publishing.
